| E-11 | M1 performance gate (lead, 20 Oct 2026; T39). Each target is measured the way a visitor gets the page. **JS:** the project page's 150 KB (gzip) budget counts initial-load JS, meaning the chunks its build manifests name for the first load, checked against the prerendered HTML (`apps/web/scripts/initial-js.mjs`, run in ci-web). Link-prefetch chunks that arrive after load are not counted. Lighthouse's whole-window script size stays an error at 200 KB. **LCP:** Lighthouse CI runs over HTTP/2, through a local TLS proxy in front of `next start` (`apps/web/scripts/lhci-h2-server.mjs`). LCP ≤ 2500 ms is an error on `/` and `/methodology`. **Measured at the gate (local, 3 runs each):** `/` 2403–2406 ms, `/methodology` 2027–2033 ms, project page 2517–2634 ms, project initial JS 152.3 KB. The project page's LCP and JS budgets stay warnings until it passes both; then they become errors. Neither target was loosened | `next start` speaks HTTP/1.1, which costs about 0.6–0.8 s of simulated LCP that no visitor sees (same build over HTTP/1.1: `/` 3.11 s, project 3.16 s, `/methodology` 2.48 s). Prefetch JS loads after the page is ready (PR #50) |
